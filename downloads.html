在 Windows 上开始创作

下载 x64 便携版，完整解压后运行 AsciiStudio.exe。转换与导出在本机完成，使用软件无需开发 SDK。

前往 GitHub Releases 下载查看更新日志

提供 Windows x64 / ARM64 ZIP。正式版、预发布版及对应文件以 Releases 为准。

三步运行便携版

在 Releases 的 Assets 列表中寻找对应架构的 ZIP：win-x64 或 win-arm64。

  1. 下载 ZIP

    在 Windows 系统信息中确认系统类型，从 GitHub Releases 获取对应 x64 或 ARM64 包。需要核对完整性时，同时下载 SHA256SUMS.txt。

  2. 完整解压

    将 ZIP 中的完整目录解压到一个文件夹。保留随包文件，避免只取出 EXE，也不要直接在压缩包内启动。

  3. 运行 AsciiStudio.exe

    从解压目录打开程序，然后导入图片或输入文字。首次创作可从入门教程开始。

    打开入门教程

核对下载文件

SHA-256 可以检查 ZIP 是否与发布方提供的文件一致。将 ZIP 和同一 Release 的 SHA256SUMS.txt 放在同一文件夹，在该文件夹打开 PowerShell。

把命令中的“<版本>”替换为下载文件的实际版本号，再执行。将输出的 Hash 与 SHA256SUMS.txt 中对应 ZIP 的值逐字比较。

Get-FileHash -LiteralPath '.\AsciiStudio-<版本>-win-x64.zip' -Algorithm SHA256
找不到文件，或校验值不同？

检查当前目录和 ZIP 文件名，确认校验文件来自同一 Release。值不同可能是文件不完整或版本不对应；重新下载对应文件后再核对。

更新前保留作品

  1. 保存并备份项目

    先保存正在编辑的 .asciiproj 项目，再复制一份备份。较新版本可能升级项目格式，升级前保留原始副本便于回退。

  2. 新版本解压到独立目录

    关闭旧程序，把新 ZIP 解压到新的文件夹，保留旧包和旧目录。避免混用不同版本的运行文件。

  3. 打开副本检查结果

    先用项目副本确认图片、文字、字体和导出。需要旧版本时，从 Releases 查找已有版本，并使用与其兼容的项目备份。

运行遇到问题

点击程序后没有打开，或提示文件缺失？

确认使用与系统架构对应的包，已完整解压，程序没有从压缩包内启动。不要混入其他版本的文件。仍无法运行时，请在 Issues 提供 Windows 版本、下载版本和错误信息。

Windows 显示发布者提示？

当前便携 ZIP 未代码签名。请核对项目地址、下载来源和校验值；无法确认提示原因时，保留提示截图并向项目反馈。

旧项目打开后显示不同，或字体缺失？

先保留原始备份，核对项目使用的字体。导入字体的项目会引用本机字体摘要；原字体缺失时，请重新导入同一字体，再检查结果。
