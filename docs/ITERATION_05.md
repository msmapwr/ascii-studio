# v0.4.0 操作与设置优化

## 范围与拆分

Medium：设置与交互优化，拆分为偏好持久化、设置页面、字体搜索与预览、动画与界面精简、次要参数修复、回归与版本整理。

使用用户已确认的默认值：全部设置类别，常用和外观优先；字体预览独立于主结果；动画遵循 Windows；默认恢复保留最近项目和创作文件；字体列表支持搜索；删除重复提示但保留限制和错误。

## 实现

- 原生 AutoSuggestBox 搜索 265 款 FIGlet 字体。独立预览 abc 或中文“测试”，后台生成并取消过时刷新。
- 设置覆盖主题、动画、紧凑布局、窗口记忆、字号、换行、统计、自动转换、等待时间、默认列数、导出格式、倍率和文件名前缀。
- 偏好以串行原子写入保存，兼容旧设置文件。
- 原生 Composition 实现页面、字体示例和约 200ms 明暗切换。系统关闭动画或开启高对比度时直接应用。
- 工具栏设置先关闭溢出菜单，再相对于工具栏打开标准 Flyout，避免嵌套弹层抢占焦点。移除旧滚轮拦截，并显示滑块当前值。
- 控件仍使用原生 WinUI NumberBox、Slider、ComboBox，未创建控件派生类。
