# 0.9 路线图

## 产品定位

**Windows 原生、离线、高质量 ASCII / ANSI 创作工具。**

创作主线：导入图片或文字 → 调整转换质量 → 编辑与比较 → 保存可继续创作的项目 → 导出作品。
每个新功能都先回答：它是否强化这个定位？不能直接改善上述主线的能力暂不进入 0.9。

## alpha.8：核心收敛与可维护性

- 提取图片、文字转换 Controller，独立管理取消、过期结果、预览与项目快照。
- 算法明确划分采样、颜色调整、边缘增强、抖动、字符映射；保留旧项目与输出兼容。
- 核心检查迁至 xUnit，按领域组织，CI 输出独立测试结果。
- README 先展示真实转换样例、软件界面与操作 GIF，再提供下载和开发说明。
- 历史迭代文档归档；保留路线、架构、格式与资源边界等长期文档。

## alpha.9：主线稳定性与交付

- 图片／文字／ANSI 的异常输入、取消竞争、项目恢复和手工编辑保护回归。
- 性能和内存预算验证；继续收薄页面中的输入读取、项目恢复与字体库呈现。
- 导出结果、色彩、透明度、Unicode 对齐、字体缺失和旧格式迁移逐项验收。
- 紧凑窗口、DPI、主题、键盘和辅助功能 UI 验收；安装／便携包和 CI 交付检查。
- 优先修复已发现的问题，不为凑版本增加新模块；未完成验收不得宣称完成。

## 冻结范围

动画转换与编辑、视频、摄像头、3D 导入及操控全部冻结，不开发、不引入依赖、不计入 0.9 验收。
复杂绘画、图层、拼贴和扩展素材平台亦不作为当前承诺；已有生成器和工具保留兼容性维护。
冻结项以后只有重新确认产品价值、成本及边界后才进入路线。

## 发布约束

剩余工作合并为 alpha.8、alpha.9 两次更新。后续如有必要可进入 beta / rc。
**用户明确允许之前，不发布正式版 1.0.0。** 本次架构整理不改变核心技术栈或项目格式。
历史计划仅用于追溯，现行范围以本文件为准。
