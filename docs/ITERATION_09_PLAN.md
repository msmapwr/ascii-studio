# v0.8 生成器可编辑项目

Medium，拆分为 Small：稳定来源参数与校验；生成器保存/恢复和自动生成联动；默认参数操作与简单验证、版本和 Push。

已一次提出六个问题。未回答的非关键项采用推荐值：全部七种生成器；打开恢复来源和已保存结果，不重新生成；参数变化遵循全局自动转换与延迟；非法输入保留已有作品；旧快照继续普通打开；重置当前生成器后遵循自动转换设置。

保存最近一次成功生成的来源参数及当前可编辑结果，未生成的参数不冒充当前结果的来源。打开后可修改参数继续创作，点击“生成”会替换手工编辑的结果。随机种子保持可复现；颜色、字体和导出继续使用共享结果栏。

参数 schema 1 和稳定 kind/style 数字标识保存在项目 Parameters 中，原文在 SourceText；项目外层仍为版本 1。未知 schema、缺失参数和非法范围明确拒绝，不猜测旧快照来源。整数尺寸验证；迷宫上限 100 × 80，其他图案 300 × 100；边框每行最多 2000 字符、最多 1000 行。

耗时生成在后台运行，连续修改合并；页面卸载、参数更新、手动生成使旧任务结果失效。生成参数继续放在结果栏上方弹层，复用响应式布局。无新依赖。

本轮不扩展生成算法、边框模板或网站全部生成器种类。按用户要求仅在模块完成后执行简单核心/UI 检查与分析器构建。
