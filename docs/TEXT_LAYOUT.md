# 文字排版与字体

适用于0.9.0-alpha.7。使用原有FIGlet和Windows系统字体，转换全程离线。文字来源、排版、字形参数和字体摘要写入v4项目；旧项目没有新参数时采用原有边框、裁剪和字体选择。

## 排版

- 字距0–20，行距0–20，左／中／右对齐。最大宽度0表示不限，否则按生成后的显示列宽限制，不包含边框。
- 默认关闭自动换行；开启后先选择空格词边界，长词再按完整字符簇拆分。超宽单个字形提示增加宽度，不裁掉笔画。
- FIGlet横向提供字体默认、完整宽度、挤紧、六项规则重叠；纵向提供字体默认、完整高度、挤紧、相等／下划线／层级／横线／竖线规则重叠。字距为正时使用完整宽度；行距为正时不重叠行块。
- 系统字体的字距每级增加4个输入字形像素，生成后随输出列数缩放；FIGlet字距以字符列计算。系统字形不使用FIGlet纵向重叠。
- 横纵内边距独立0–30；标题嵌入上边框。双列中文标题按显示列宽补齐，标题过长时扩展边框。

## 字体库

字体搜索、分页预览网格、收藏、字体高度／基线／排版标记／摘要／原始说明。每页12款，关闭弹层或换页取消旧预览；单个预览显示最多2000个UTF-16单元，保持字符簇完整。默认abc，也可比较当前输入前24个字符簇。非ASCII样本提示切换abc；FIGlet转换仍限定ASCII输入。

导入`.flf`时验证后按SHA256摘要复制到本地字体目录，重复内容复用同一文件，显示原文件名。文件上限2MB、本地最多256款、字体高度最多128行；为避免原解析器空白计数溢出，拒绝超过254的连续首尾空白和超过2048的行。字体没有执行脚本或加载外部资源。用户需自行遵守所导入字体的许可。

项目引用字体摘要，不嵌入字体文件。缺失时保留已保存结果并提示导入原字体；不会自动生成替代作品。已有内置字体参数按名称兼容映射。解析字体最多缓存64个布局变体。生成前用完整字形宽度估算并拒绝超过400万单元的行块，避免异常字体造成巨大分配。

FIGlet规则使用重新解析布局头实现。此方式避开现有Figgle库中布局覆盖仅部分生效的问题，原字体文件保持不变。实现依据[Figgle字体解析器](https://github.com/drewnoakes/figgle/blob/master/src/Figgle/FiggleFontParser.cs)和[渲染器](https://github.com/drewnoakes/figgle/blob/master/src/Figgle/FiggleFont.cs)。

## 中文与混排

常规／粗体，0–12源像素描边，实心／空心；空心要求描边大于0。中文清晰预设200列／粗体／1px描边／字距2／行距1；混排均衡160列／粗体／字距1／行距1；紧凑96列／常规／字行距0。输入字体负责字形，结果字体及其宽高比决定字符画排列；中文保持已有更大显示字号。

缺字检查使用所选字体的GDI字形索引。缺失或需回退时显示提示，默认暂停生成；可在“中文字形”勾选仍然生成。字体回退、emoji和复杂文字的GDI+外观可能不同于浏览器，提示不能保证所有组合字形的排版质量。

系统字体逐字符簇绘制，保留组合字符；不提供阿拉伯文等复杂文字的跨簇连字排版保证。单个栅格画布上限2000万像素和32767单边，超过时提示减少内容。结果总画布仍受400万单元限制。

## 验收

核心检查增加7项排版断言；Windows专项检查覆盖导入／去重、规则变化、收藏持久化、坏文件／超大文件、摘要／缺失、全部内置字体及正字距、宽字形分配保护、中文描边／字重／缺字与项目参数往返。UI脚本为`scripts/ui-text-layout-tests.ps1`，实际验收结果记录到实施计划后才标记模块完成。
