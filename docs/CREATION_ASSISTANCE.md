# 创作辅助

## 注释

结果工具栏 → 注释 → 选择语言 → 生成预览。默认优先行注释；HTML、XML、CSS、OCaml 等仅有块注释时自动使用块形式。支持 C/C++/C#/Java/JavaScript/TypeScript、Python、Shell、SQL、Lua、Rust、Go 等 40 多种语言及格式。

复制不改变结果。替换需要确认；本次会话可恢复注释前的完整字符画，包括字体和颜色。重新生成、手动修改结果或关闭程序后，原文恢复不作为通用撤销历史保存；需要长期保留时先保存项目。

保留空格与行结构，统一 LF 换行。块结束符冲突会提示错误；HTML/XML 的 `--` 会被拒绝。Python 不将三引号字符串作为注释。包装后仍受字符画网格限制。

## 教程与新手模式

导航底部的使用教程简要介绍图片、文字、预览、项目、导出、注释与加密。教程和设置都能切换新手模式；开启后在细致设置下显示用途和边界说明，默认关闭。

## 界面字体

设置 → 界面字体 / 界面字号。可搜索已安装字体，字号为 12–24，标题按比例调整。字符画、字体示例与代码预览保留自己的字体。设置保存到本机；旧设置缺少字段时使用 Segoe UI、14 和关闭新手模式。
