# v0.7 ANSI 查看器

## 范围和分级

Medium：一个独立 ANSI 查看功能，沿用 WinUI 3/.NET 10。拆分 Small：

1. 文档可选背景颜色网格，位图/HTML/SVG/ANSI 导出兼容。
2. 有资源边界的 ANSI 状态解析器、UTF-8/CP437 解码和基本 SAUCE 元数据。
3. 文件/拖放/粘贴/示例入口，颜色预览、参数和原文项目恢复。
4. 模块完成后简单核心/UI 检查、分析器构建、格式检查，版本和 Changelog，Push。

## 澄清与默认值

已提出 8 个问题；非关键项未答复时采用推荐项：独立导航、文件和粘贴与示例、自动严格 UTF-8 检测并允许 CP437 手动切换、16/256/真彩色及前背景色、常见光标/擦除、忽略未知指令并统计、80 列可调 20–300、UTF-8 或原始文件最多 4 MB、2000 行、静态闪烁及可选 iCE 高亮背景。保存原文和解析参数，复用现有导出。

## 边界

仅解析显示，不执行任何终端命令、OSC 链接或系统操作。只保留最后的静态画面；不是完整交互终端。仅支持本轮列出的控制指令；IBM/Amiga 专用字体、全屏、PDF 和 WebP 留在后续功能清单。Unicode 显示仍受现有 UTF-16 字符网格与字体回退限制。

旧文档无背景网格时保持原显示和导出。SAUCE 支持尾部 128 字节 00 记录与有效 COMNT 注释，元数据和原文正文分离；无效/截断记录不导致越界。原始字节随项目保存，编码切换可重新解码；粘贴文本以 Unicode 原文保存。

按未回复的非关键问题采用推荐方案。44/44 核心检查通过；2/2 简单 UI 检查覆盖彩色示例、原文/参数恢复、未知指令统计与解析错误保留结果。彩色预览截图已检查，分析器构建 0 警告/0 错误。详细使用和兼容范围见 [ANSI 查看器](ANSI_VIEWER.md)。完整终端金样、实体文件对话框/拖放与所有 SAUCE 变体不在本轮简单自动化覆盖内。
