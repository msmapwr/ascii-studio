# 图片质量与性能

适用于 0.9.0-alpha.6。旧项目默认继续使用原来的字符顺序和转换算法；新创作默认启用当前显示字体的密度测量。结果栏上方的“字符”设置可以切换。

## 风格

| 风格 | 用途 | 采样 |
|---|---|---|
| 密度字符 | 照片和明暗纹理；标准、极简和字母字符集使用严格 ASCII | 每字符1点 |
| 结构线条 | 建筑、Logo 和线稿，用水平、垂直及对角字符表达局部边缘方向 | 每字符1点 |
| Braille 点阵 | 每字符2×4点，需要支持 Braille 字形的字体和终端 | 每字符8点 |
| 半块双色 | `▀` / `▄` / `█`；彩色模式分别保存上半前景和下半背景，单色模式使用阈值和抖动 | 每字符2点 |

字体比例补偿仍使用实测字符宽度和行高。原图像素尺寸按处理区域和基础13px字体换算；透明裁剪也参与换算。自定义固定宽高仍可能拉伸。预览、位图和SVG按精确半格绘制块字符，HTML使用半格渐变并保留可复制原文；纯文本终端的半块接缝仍取决于字体。

密度排序以32px字形在字符格内的笔画覆盖面积为依据，归一化最浅与最深字符后匹配。结构模式是局部方向检测；不会识别物体语义。“自适应”默认0，逐渐提高可平滑平坦区域并增强边缘；过强会改变细节。

## 透明与颜色

- “透明合成背景”接受 `#RRGGBB`；关闭透明留空时，透明区域与该颜色合成。
- “透明区域留空”按采样区域平均 Alpha 判定，保留半透明颜色；抖动不会向透明单元扩散。
- “裁去透明边缘”在裁剪/旋转/翻转后应用，按阈值移除外边缘。全部透明时保留1×1透明处理图，原图仍保存于项目。
- 调色板提供原图真彩色、双色、自定义、渐变、ANSI16/256和2–64色限制。双色使用前两个颜色；自定义最多64个颜色，以逗号分隔。
- 渐变沿输入颜色顺序插值，按颜色距离匹配；限色使用加权中位切分。映射以5位RGB桶复用最近颜色，细小颜色差异可能合并。
- 彩色半块同时量化前景和背景。ANSI16/256使用相应终端控制序列，其他调色板使用真彩色。
- HTML/SVG与图像预览保留颜色Alpha。位图沿用现有画布背景；此选项不代表导出PNG背景透明。终端不支持半透明，ANSI导出使用不透明RGB，空背景使用默认背景。

## 性能和取消

每项目保留缓存最多64MiB，全局最多256MiB，最多2048项，使用LRU淘汰；预算包含数组、文本和预留索引开销。当前原图、历史以及正在计算的数据分别计入应用工作内存，不包含在缓存预算中。可在“性能”中查看缓存使用、阶段复用次数并清空本项目缓存。

原图解码、几何/透明裁剪、采样、滤镜、字符映射和图像缩略预览分别缓存。滤镜调整可复用采样；字符集/抖动/调色板改变可复用滤镜。缓存键保存输入摘要和参数，不引用大像素数组；切换历史时相同来源可再次复用。旧算法的完整输出也缓存。

连续调整遵循全局自动转换等待时间。超过120列时先生成最多120列临时预览，再等待300ms生成完整结果；临时预览不进入作品、历史、复制或保存。关闭自动转换时点“转换”直接生成完整结果。已有手工编辑时跳过临时预览，完整结果作为可接受的候选版本出现。

新任务取消前一任务；采样、滤镜、映射、透明裁剪和颜色处理按行或4096项检查取消。最终索引和历史快照在后台计算，提交前再次检查取消和手工编辑。原生图像解码调用本身不可中途终止。取消按钮仅在当前任务活跃时可用。

转换期间可点结果栏上方的“取消转换”或按 Esc。次要设置输入完后点“完成设置”，数字输入会先提交，自动转换遵循已有等待设置。

输出最多2000列、2000行，最多400万采样点：密度/结构400万字符，半块200万字符，Braille50万字符。超过限制会提示降低分辨率，不会偷偷改变比例。输入保持40MB文件、8000万原始像素、解码最长边2400px的现有限制。处理区域尺寸显示在缩略图旁。

项目格式升级为v4，读取v1–v3；覆盖旧项目前保留最近一个迁移前`.bak`。格式升级用于保存新增质量参数和ANSI色彩编码。
