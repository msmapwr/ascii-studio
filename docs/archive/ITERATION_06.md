# v0.5.0 图片裁剪与方向

## 范围与拆分

Medium：图片几何预处理，拆为平台独立像素变换与历史、原生设置弹层、转换与缩略图同步、项目持久化、颜色事件修复、验收与版本整理。

六项需求已由用户确认：工具栏弹层；左转、右转与 180°；左/上/宽/高百分比；遵循自动转换设置；几何调整专用撤销/重做；原图与参数一并保留。

## 行为

- 先裁剪，再顺时针旋转，最后在旋转后的坐标中翻转。
- 百分比以 EXIF 方向校正后的源图为基准；沿用最长边 2400 的处理分辨率限制。分数像素裁剪向外取整，最小保留一个像素。
- 原始图片字节始终保留；几何变化不反复修改原图。图像预览显示处理后的尺寸。
- “应用裁剪”显式提交四个输入；非法区域提示错误并保留最后成功结果。
- 旋转、翻转、裁剪和重置记录参数历史，最多撤销 40 步。导入另一张图片或重开项目时建立新的历史基线。
- 关闭自动转换时只更新图像预览，点击“转换”才更新字符画。
- 项目格式仍为版本 1，增加可选 Geometry 字段；旧文件缺少该字段时使用完整原图和默认方向。
- 并发转换可取消；缩略图工作串行执行，过时的预览不覆盖新状态。
- 打开项目取消旧转换；没有原图的项目清空旧预览并禁用几何操作。
- 修复生成结果被延迟 TextChanged 当作人工编辑的问题，保留颜色网格。

## 验证

- 核心检查包含 16 种旋转/翻转组合、像素与透明度、裁剪顺序、边界、取消、原图不可变、40 步历史和 JSON 往返。
- 核心检查 31/31，完整 UI 批次 9/9 通过；构建 0 警告、0 错误，修改文件的格式检查通过。
- UI 脚本使用独立测试数据目录，通过真实项目恢复入口打开旧版本图片项目，检查转换、撤销/重做、非法裁剪、原图与参数恢复、手动转换、颜色保存及窄窗口。
- 构建使用 win-dev-skills 的 BuildAndRun.ps1 和 WinUI 分析器；格式检查只覆盖本轮修改文件。
- 提交前按 winui-code-review 检查参数验证、后台处理、资源释放、原生控件和自动化标识；沿用现有程序式界面架构。
- 本轮未新增自由角度旋转或拖动裁剪框，也未生成新的 MSIX。
- 窄窗口的弹层采用内部滚动，并检查视口边界与底部操作可达性。首次加载测试使用固定项目文件，不依赖随创作变化的恢复快照。
