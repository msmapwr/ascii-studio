## 1. 产品目标与默认决策

制作一个适合日常创作、终端展示、社交分享和程序化批处理的 Windows 原生 ASCII art 工具。用户导入图片或输入文字，调整少量直观参数，即可获得比例正确、可编辑、可复制、可导出的结果；高级用户能控制映射算法、字符集、颜色、批处理和动画。

- 名称暂定 AsciiStudio，中文优先，完整支持英文界面。
- UI 采用 WinUI 3；主要运行平台为受支持的 Windows 11，首发 x64，正式版增加 ARM64。
- 默认离线完成所有转换，不上传原图或文字。网络仅用于用户主动触发的更新检查或可选资源获取。
- 1.0 提供完整静态图片与文字工作流；1.1 加入批量和命令行；1.2 加入动画。所有阶段属于本计划的最终范围。
- 纯 ASCII 模式严格使用可打印 ASCII 字符；Unicode 模式单独提供块字符、Braille 等风格，结果与导出明确标识。
- 首发不绑定商业服务。收费方式、开源许可证和商店发布由产品所有者在发布阶段决定。

## 3. 用户主流程

1. 打开应用，选择图片转换或文字转换。
2. 拖入文件、从剪贴板粘贴图片，或输入文字。
3. 应用立即生成预览，按内容推荐一个起始预设。
4. 调整列数、风格、对比度与配色；预览随操作更新。
5. 对比原图与结果，必要时裁剪、旋转、编辑字符。
6. 复制到剪贴板，或导出文本、HTML、SVG、PNG 等格式。
7. 保存项目，稍后恢复输入、参数及编辑内容。

首次启动不要求注册；空状态展示可直接使用的示例与拖放提示。转换、保存、导出均提供清楚的完成状态和可恢复错误提示。

## 5. 图片转换参数与算法

### 5.1 参数设计

基础设置默认可见：风格、输出列数、亮暗方向、对比度、颜色模式、等宽字体。高级设置折叠：采样方式、Gamma、边缘强度、抖动、字符比例、透明背景、调色板、颜色空间。

- 列数提供常见值及手动输入；过大时显示预计字符数、内存和导出尺寸。
- 字符集提供简约、标准、细节、线条、块字符、Braille 等预设。
- 自定义字符集去重，保持用户顺序；自动密度排序可开关。空字符集、控制字符、组合字符和宽字符分别校验。
- 同一组参数必须能复现相同结果，保存到项目和预设中。

### 5.2 基础管线

解码 → 校正方向与透明背景 → 裁剪与变换 → 色彩/亮度预处理 → 按字符单元重采样 → 字符与颜色匹配 → 生成结构化网格 → 预览与导出。

灰度计算考虑 sRGB 与线性亮度的转换；透明像素先按用户背景合成。输出行数按图像宽高与实测字形单元比例推导：`行数 ≈ 列数 × 图像高度 / 图像宽度 × 字符单元宽度 / 字符单元高度`。用户可锁定行列数或显式覆盖比例。

基础模式使用区域平均亮度，避免仅取中心像素造成细节丢失。字体变化时重新计算密度表；密度计算包含实际字号、抗锯齿和字形覆盖率，缓存键覆盖所有相关参数。

### 5.3 高质量模式

- 密度匹配：按实测字形覆盖率匹配单元亮度。
- 边缘保留：根据方向梯度选择 `/`、`\\`、`|`、`-` 等字符，控制强度，避免过度噪声。
- 结构匹配：比较图像单元与候选字形的小尺寸特征图，综合亮度、方向、局部对比与结构误差。
- 抖动：提供关闭、有序抖动和误差扩散；动画默认选择稳定模式减少闪烁。
- Braille：明确按 2×4 点阵编码，提供阈值、抖动和反转。
- 自动预设：依据局部对比和边缘统计建议照片/线稿/标志风格，允许立即覆盖。

各模式使用同一标准样本集比较视觉质量和耗时；高质量模式先完成 CPU 基线，再根据实测决定是否增加 GPU 加速。

## 6. 文字转换与编辑规则

字体栅格化模式使用 Windows 字体塑形与回退能力，将文字渲染为中间图像后复用图片转换管线。支持中文、标点、多行、空格、emoji 的回退；缺失字形必须提示，不静默替换成方框。

艺术字模式提供经过许可核对的内置字体；FIGlet 字体的许可证单独记录。中文输入默认推荐字体栅格化模式。字体文件解析限制尺寸和复杂度，格式错误不影响其他项目。

编辑内容以字符网格为基础，包含字符、前景色和背景色。保留算法生成的基础结果与用户编辑层；重新转换时提示保留、重置或另存版本，避免覆盖手工修改。裁剪或网格尺寸变化后不能可靠映射编辑层时，明确说明并提供恢复路径。

撤销重做覆盖编辑和参数修改；拖动滑块合并为一次操作。纯文本粘贴支持 CRLF/LF、Tab 展开、宽字符策略和网格扩展确认。

## 7. 界面与交互设计

采用 Fluent 风格：原生标题栏、NavigationView、圆角卡片、浅色/深色/跟随系统、可用时采用 Mica。高对比度和减少动画设置优先于装饰效果。

- 左侧导航：图片转换、文字转换、批量处理、预设、最近项目、设置。
- 主工作区：输入与结果并排，可调分隔线；窄窗口改为页签或上下排列。
- 右侧参数面板：基础/高级分组，相关参数联动显示；预设选择位于顶部。
- 底部状态：源尺寸、网格尺寸、字符数量、耗时、当前任务及进度。
- 导出面板：格式、文件名、尺寸、字体、背景、换行和编码；提前展示格式限制。
- 首次体验：一个图片示例、一个中文示例、一个英文艺术字示例；无阻断式长教程。

快捷键：Ctrl+O 打开、Ctrl+S 保存、Ctrl+Shift+S 另存为、Ctrl+E 导出、Ctrl+Z 撤销、Ctrl+Y 重做；复制仅对有意义的选区/结果生效。所有核心操作可仅用键盘完成，焦点顺序、读屏名称和禁用原因完整。

转换不阻塞 UI；拖动参数时采用约 150ms 防抖，先生成快速预览，随后生成高质量结果。取消旧任务并以版本号阻止过期结果覆盖新设置。转换失败保留最后一次成功结果，显示失败原因和重试入口。

## 8. 导出规范与兼容性

| 格式 | 内容与规则 | 验收要点 |
| --- | --- | --- |
| TXT | UTF-8，ASCII 可选；LF/CRLF；可选 BOM；保留行尾空格 | 空格、行列与字符不丢失 |
| ANSI | 明确 16 色、256 色、TrueColor；包含重置序列 | 在声明支持的终端中验证颜色和宽度 |
| HTML | 转义文本；等宽字体；保留空白；按颜色合并片段 | 无外部资源、脚本或字体下载，打开可查看 |
| SVG | 转义 XML；固定单元定位；控制节点数 | 标明字体依赖，提供转路径选项的技术评估 |
| PNG | 实际渲染字符；可选透明背景；明确像素尺寸 | 与应用预览一致，超大图按内存预算处理 |
| JPEG | 需合成不透明背景，质量可选 | 透明来源导出前明确背景颜色 |
| PDF | 页面尺寸、边距、分页、嵌入许可允许的字体 | 可搜索文本与视觉一致性分别验证 |
| 动画 | 帧率、帧范围、背景、分辨率 | 时长正确、颜色一致、无明显字符闪烁 |

所有导出使用同一结构化结果快照。采用临时文件与原子替换；覆盖已有文件明确确认；磁盘空间不足、目录无权限、文件占用可重试。导出透明 PNG 与复制文本是不同能力，UI 清楚区分。

SVG 使用文本时无法保证目标机器有相同字体；转路径涉及字体许可和文件大小，需要单独验证。视频导出依赖的编码器可用性也必须显式检测。

## 9. 项目、预设与数据存储

- 项目扩展名暂定 `.asciiproj`，版本化容器包含 JSON 参数、字符网格、编辑层和可选嵌入原始素材。
- 默认嵌入输入，保证可移动和离线恢复；大文件可选外部引用，记录相对路径及内容校验值，缺失时可重新定位。
- 新旧版本迁移可验证且有备份；未知字段容忍读取，未知重大版本避免静默覆盖。
- 自动恢复存储于应用私有数据目录，周期可调；异常关闭后提示恢复，正常关闭清理对应恢复项。
- 最近文件记录路径与时间，可清空；不存在的文件可从列表移除。
- 预设为可读 JSON，包含算法版本与兼容性信息；导入验证字段、范围及大小。
- 设置记录主题、语言、默认字体、导出目录、缓存限制；项目参数不混入全局设置。
- 保存和导出不得要求管理员权限；日志默认不包含原图、完整输入文字或敏感文件路径。

## 10. 技术架构与依赖策略

建议 .NET 10 LTS + C# + WinUI 3，采用环境配置时核实的受支持 Windows App SDK Stable 版本。使用 `global.json`、明确包版本和锁文件保证可复现构建；现有 net8/SDK 1.6 骨架迁移前需检查模板、XAML 编译器与依赖兼容性。

分层如下：

```text
src/
  AsciiStudio.App/           WinUI 窗口、页面、样式、应用生命周期
  AsciiStudio.Core/          网格、参数、算法、预设模型；不依赖 WinUI
  AsciiStudio.Application/   用例、任务调度、撤销重做、批量队列
  AsciiStudio.Infrastructure/解码、字体栅格化、导出、存储、平台适配
  AsciiStudio.Cli/           命令行入口，复用应用层
tests/
  Core.Tests/               算法与确定性
  Integration.Tests/        解码/字体/导出/存储
  Ui.Tests/                 主流程与无障碍
  Benchmarks/               性能与内存基准
docs/                       产品、架构、格式规范、发布说明
```

- UI 使用 MVVM；CommunityToolkit.Mvvm 负责可观察状态与命令，其版本在实施时固定。
- 原始结果用紧凑网格存储，避免为每个字符创建 UI 控件；大型彩色结果使用适配 WinUI 的绘制层，静态文本结果可走文本渲染路径。
- Windows 解码与文字塑形优先采用平台能力，接口隔离平台依赖。Win2D/DirectWrite 或替代方案先做小规模兼容性原型，再确定渲染实现。
- 任务支持 CancellationToken、进度和资源预算；使用缓冲池、分块处理、解码降采样与有界并发。
- 图片预览缓存、中间结果缓存和字体特征缓存分别管理，缓存可清空且有上限。
- 更新检查为用户主动操作；首发不实现应用内自动下载安装。
- 视频阶段在 Media Foundation 与 FFmpeg 方案之间做兼容性、编码器及许可评估，不提前捆绑未审查的可执行文件。

## 11. 质量标准与性能目标

以下为验收目标，基准机器建议 Windows 11、6 核 CPU、16GB RAM、SSD、1920×1080；在正式开发前记录具体型号、功耗模式与版本。计时区分解码、转换、绘制和导出，报告中保留 p50/p95。

| 指标 | 初始目标 | 检验方式 |
| --- | --- | --- |
| 冷启动 | 首个可操作窗口 ≤ 3 秒 | 10 次独立启动，记录 p95 |
| 常规预览 | 1080p 输入、120 列基础模式转换+显示 p95 ≤ 300ms，不含首次解码 | 固定图集与参数 |
| 高质量转换 | 4K 输入、200 列 p95 ≤ 2 秒，不含导入 | 同一图集，记录各步骤耗时 |
| 参数响应 | 可见反馈 ≤ 100ms，最终结果允许随后完成 | 输入到状态更新延迟 |
| 内存 | 单张 4K 常规转换工作集目标 ≤ 500MB | 连续导入与转换，观察峰值 |
| 可取消 | 取消后 ≤ 500ms 停止计算或进入明确的不可取消收尾 | 慢任务与批量任务 |
| 稳定性 | 连续 100 次导入/转换/关闭，无崩溃和持续内存增长 | 压力场景及资源监测 |
| 比例正确 | 标准几何图像在声明字体下不出现明显拉伸 | 圆形与网格样本，量化容差 |
| 无障碍 | 主流程可键盘完成、读屏可识别；100–200% DPI 正常 | 人工与自动 UI 检查 |
| 离线能力 | 安装运行所需依赖满足后，转换/保存/导出无需网络 | 断网验收 |

超大图片设置解码像素上限、输入尺寸及内存预算；超限时可降采样，并清楚告知实际处理分辨率。批量并发默认依据内存预算确定，不直接按 CPU 核数启动大量 4K 任务。

视觉样本集覆盖人像、风景、黑白线稿、Logo、小字、透明图、低对比、纯黑/白、渐变和噪声。每种算法保留参考结果；视觉评估结合结构指标与人工检查，不能仅用单一分数判定质量。

## 12. 测试与安全边界

- 单元验证：行列推导、亮度映射、透明合成、Braille 位序、边界参数、字符集、撤销重做、命名规则。
- 集成验证：EXIF、ICC/颜色处理、损坏文件、宽字符、字体回退、所有导出格式、项目往返和版本迁移。
- 界面验证：打开→调整→复制→导出→保存→重开；取消、失败、恢复、缩放、键盘和高 DPI。
- 基准验证：固定输入、参数与版本，避免用变化样本比较算法性能。
- 批量验证：部分失败继续处理、取消后不产生伪成功、路径冲突、长路径、同名文件、空目录。
- 输入约束：图片像素数量、动画帧数、容器解压后大小、字体文件与 JSON 深度有上限；检查容器路径穿越。
- 导出约束：HTML/XML 转义，ANSI 输出去除用户输入中的控制序列；导出目录和文件覆盖受控。
- 依赖验证：记录第三方库、字体、编码器许可证与来源；依赖更新有兼容性检查。
- 用户诊断：日志可查看、清空；导出诊断包前显示包含项目，不自动发送。

## 15. 完成定义与风险处理

“完整”表示每个声明支持的输入、算法和输出都有实际实现、错误处理、文档及验收证据；正式功能矩阵不能包含仅计划中的选项。

| 风险 | 处理策略 |
| --- | --- |
| WinUI/SDK/运行时版本不匹配 | S0 最小项目验证，固定版本，依赖升级单独检查 |
| 字符密度随字体变化 | 实测覆盖率与字体特征缓存，保存项目字体信息 |
| 中文、emoji 和终端宽度不一致 | 区分栅格化输入与输出字符集，声明目标字体/终端，验证宽字符策略 |
| 大字符网格造成 UI 卡顿 | 紧凑数据、专用绘制、可见区域渲染，避免每字符 UI 元素 |
| 大图和批量内存溢出 | 解码降采样、像素限制、缓冲复用、有界并发 |
| 动画字符闪烁 | 确定性映射、固定色板、时间平滑与专门样本集 |
| 保存/导出损坏或丢失编辑 | 快照、临时文件、原子写入、编辑层、恢复副本 |
| 特殊格式与视频分发受限 | 检测能力、依赖隔离、许可证清单、明确支持范围 |

允许后续扩展云同步、在线素材、AI 辅助风格和插件，但它们不属于本计划验收范围，也不影响本地转换完整性。
