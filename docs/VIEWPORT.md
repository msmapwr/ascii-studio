# 大结果视图与原图对比

## 查看和编辑

结果工具栏的“视图”提供适应窗口、适应宽度、定位到选区。适应模式会随窗口尺寸变化重新计算，可以低于 25%；手动按钮或 Ctrl+滚轮继续使用 25%–400%，恢复 100% 会退出适应模式。自动适应比例不写入全局偏好。Shift+滚轮横向滚动，滚轮向上向左、向下向右。

图像预览只分配可见区域位图，滚动更新合并为 60ms，过期工作取消，最多一个后台绘制任务。按实际显示缩放绘制；极大视口受 4096 像素单边及 400 万像素预算限制，可能降低绘制密度。可见字符超过约 10 万列位时抽样为概览，放大后显示字符细节。预览不改变作品内容及导出尺寸，位图导出仍受原有 4000 万像素上限限制。

超过 20 万 UTF-16 单元的结果默认进入图像预览。关闭“显示 → 图像预览”后按页编辑；翻页按钮与跳到行仅在大结果中显示。页目标上限为 64000 单元或 200 行，不切断 Unicode 字符簇；单个极长字符簇可能超出这个软上限，整个文档仍受现有安全限制。单行也可以分成多页。修改、撤销、复制、保存、恢复和导出作用于完整作品，而非仅当前页。手工编辑会重置前背景色，沿用原有编辑语义。

“定位到选区”将编辑光标起点对应的行列移入图像视口，保留当前缩放；跨页选区暂不支持，可用跳到行定位。生成时原始结果与注释弹层只显示开头节选，复制或替换仍使用全文。

## 图片对比

“原图对比”提供结果、原图、并排、分界线四种模式；只有带源图片的项目可用。对比默认使用裁剪、旋转和翻转后的图像，也可选原始图片；这里不模拟亮度、颜色及字符映射滤镜。对比图按最长边 2400 像素生成，第一次打开对比时才解码为显示位图。

默认同步缩放及相对滚动位置，取消同步后可分别滚动，并通过原图上的 Ctrl+滚轮独立缩放；底部缩放按钮控制结果。分界线模式始终保持两侧缩放和位置对齐；可拖动分界线，也可使用设置中的滑块进行键盘调整。原图保留宽高比并映射到结果的显示区域，自定义拉伸网格仍会与原图存在比例差异。

结果区域不足 640 DIP 时，并排与分界线自动显示单独原图；可通过“对比方式”切换“结果”或“原图”。窗口变宽时恢复所选对比方式。结果和原图都保留滚动位置，不通过缩小整个界面字体腾出空间。

## 验证

核心索引检查位于 `tests/AsciiStudio.Core.Tests/ViewportTests.cs`；UI 脚本为 `scripts/ui-viewport-tests.ps1`，使用 `artifacts/alpha5-ui-data` 隔离目录。先执行 `-Prepare`，以 `ASCIISTUDIO_DATA_DIRECTORY` 指定该目录启动应用，再传入 `-AppPid`。截图包含百万字符概览、行定位、并排、分界线及 480 DIP 窄窗口；Windows 命令行不承载整页文本，UIA 使用短文本替换页并核对保存文件的未显示内容。

仅验证当前实际显示缩放；实体跨显示器缩放切换仍须实机验收，不宣称已经覆盖。
