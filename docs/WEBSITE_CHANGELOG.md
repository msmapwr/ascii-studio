# 网站 Changelog

网站与桌面应用独立记录版本，使用 Semantic Versioning 和 Keep a Changelog。桌面应用的记录仍在仓库根目录的 CHANGELOG.md。

## [Unreleased]

## [0.10.0-alpha.1] - 2026-10-03

### Added

- 独立的软件更新日志页，展示仓库中 19 个带日期的版本及全部分类条目，提供版本索引与下载入口。
- 从根目录 CHANGELOG 和公共页面导航生成静态日志的脚本，并检查生成页面是否过期。
- 品牌紫柔光、首屏渐入、截图一次高光扫描、按钮悬停与按下反馈、导航和弹层短动画。
- 顶部阅读进度、版本索引当前状态与跳转高亮；手机版本索引可横向滚动。

### Changed

- 首页与日志页共用主题、手机导航和脚本；演示播放仅在含演示的页面初始化。
- 网站检查覆盖两页的素材、锚点、跨页链接、文案与无障碍引用。
- 减少动态效果模式关闭新增动画、过渡及流畅滚动，高对比度关闭装饰光效。

## [0.9.0-alpha.1] - 2026-10-03

### Added

- AsciiStudio 中文介绍页，展示真实应用截图、图片与文字转换对照、功能、创作流程、下载方式和常见问题。
- Fluent UI Web Components 外观选择，支持系统、浅色与深色主题，并保存本机偏好。
- 固定顶部导航和手机折叠菜单；Release 链接在新标签页打开。
- 操作 GIF 进入视野播放，离开视野恢复静态图，可手动停止；减少动态效果模式使用静态图。
- GitHub Pages 静态发布目录；脚本或组件 CDN 不可用时仍可阅读、展开 FAQ 和访问下载链接。
- 内容、素材、锚点与无障碍标签检查脚本。

首版不添加访问统计。此次网站发布不改变桌面应用版本。
