# 网站 Changelog

网站与桌面应用独立记录版本，使用 Semantic Versioning 和 Keep a Changelog。桌面应用的记录仍在仓库根目录的 CHANGELOG.md。

## [Unreleased]

## [0.12.0-alpha.3] - 2026-10-03

### Added

- 帮助中心提供 12 个问答，支持本地多关键词搜索、结果计数、空结果提示和清除恢复；无脚本仍可阅读全部问答。

### Changed

- 根据已合并的 0.9.0 记录更新下载与架构说明，区分 ARM64 构建包与实机验收。

## [0.12.0-alpha.2] - 2026-10-03

### Added

- 导出格式指南按用途比较九种格式，说明颜色、字体、透明度和导出预算。
- 顶部资源菜单与页脚入口，原生菜单支持键盘与无脚本访问。

## [0.12.0-alpha.1] - 2026-10-03

### Changed

- 更新日志打开时读取仓库 main 的 Changelog，保留全部有日期的版本和分类。
- 网络失败、脚本关闭或读者已定位版本时保留发布时静态记录，并说明当前来源。

## [0.11.0] - 2026-10-03

### Added

- 入门教程、真实作品展示和独立下载与运行页，公共导航贯通五个页面。
- 示例复制、原图对比滑块、类型筛选、原生放大、TXT／ANSI 下载与 SHA-256 校验说明。

### Changed

- 访客页面从校对后的 XML 静态生成，下载信息沿用 Releases，软件更新日志沿用仓库 CHANGELOG。
- 手机导航、跨页主题、复制失败和无脚本降级经过浏览器检查；不引入访问统计或文件上传。

## [0.11.0-alpha.3] - 2026-10-03

### Added

- 独立下载与运行页，提供 Release 入口、便携 ZIP 三步、SHA-256 校验命令与更新备份说明。
- 下载失败、运行文件缺失、发布者提示与旧项目字体问题的折叠排查。

### Changed

- 公共导航与页脚加入下载页；Release 外链继续在新标签页打开。
- 复制成功或失败反馈显示在对应按钮旁，保留原文字供手动复制。

## [0.11.0-alpha.2] - 2026-10-03

### Added

- 作品展示页，图片／文字筛选、默认各半的原图对比滑块、可展开参数及原生放大对话框。
- 两组真实源图与结果，以及 TXT 和 ANSI 原始作品下载；完整保留图像比例。
- 滑块支持方向键、Home 和 End，对话框支持 Escape、关闭按钮和焦点恢复；无脚本时显示静态并排对照。

### Changed

- 公共导航改为产品介绍、教程、作品及更新日志页面入口。

## [0.11.0-alpha.1] - 2026-10-03

### Added

- 入门教程页，覆盖图片转换、文字与中文排版、项目保存和常用导出格式。
- 真实样例图、步骤目录、流程排查及示例文字复制；复制不可用时保留手动选择。
- XML 访客页面文案与静态生成脚本，并检查源文案和生成页面一致性。

### Changed

- 公共导航加入教程入口；手机折叠断点调整为 1000px，保留完整导航。

## [0.10.0-alpha.1] - 2026-10-03

### Added

- 独立的软件更新日志页，展示仓库中 19 个带日期的版本及全部分类条目，提供版本索引与下载入口。
- 从根目录 CHANGELOG 和公共页面导航生成静态日志的脚本，并检查生成页面是否过期。
- 品牌紫柔光、首屏渐入、截图一次高光扫描、按钮悬停与按下反馈、导航和弹层短动画。
- 顶部阅读进度、版本索引当前状态与跳转高亮；手机版本索引可横向滚动。

### Changed

- 首页与日志页共用主题、手机导航和脚本；演示播放仅在含演示的页面初始化。
- 网站检查覆盖两页的素材、锚点、跨页链接、文案与无障碍引用。
- 减少动态效果模式关闭新增动画、过渡及流畅滚动，高对比度关闭装饰光效。

## [0.9.0-alpha.1] - 2026-10-03

### Added

- AsciiStudio 中文介绍页，展示真实应用截图、图片与文字转换对照、功能、创作流程、下载方式和常见问题。
- Fluent UI Web Components 外观选择，支持系统、浅色与深色主题，并保存本机偏好。
- 固定顶部导航和手机折叠菜单；Release 链接在新标签页打开。
- 操作 GIF 进入视野播放，离开视野恢复静态图，可手动停止；减少动态效果模式使用静态图。
- GitHub Pages 静态发布目录；脚本或组件 CDN 不可用时仍可阅读、展开 FAQ 和访问下载链接。
- 内容、素材、锚点与无障碍标签检查脚本。

首版不添加访问统计。此次网站发布不改变桌面应用版本。
