## 已落地

项目拆分为跨平台逻辑 `AsciiStudio.Core` 和 WinUI 应用 `AsciiStudio`。实现图片转换、FIGlet / 中文字体转换、7 个基础生成器入口、9 项文本处理、可编辑结果、9 种文件导出、项目存取、最近项目、恢复快照和主题设置。详细功能见 README。

开发环境已安装 VS WinUI 工作负载和 Windows SDK 26100，NuGet 依赖已恢复。Debug 构建完成，0 警告 / 0 错误；原生窗口成功启动。主题资源在窗口首次显示后发现问题并修正。

只完成编译和启动观察，未执行自动化测试或完整功能验收。因此覆盖表中相关需求标记「部分实现 / 未验证」，不能用构建成功代表转换算法、导出、项目往返等验收通过。

## 当前限制

- 图片转换尚缺裁剪旋转界面、透明边距、字体密度实测、参考样本对比与批处理。
- FIGlet 有内置字体选择，尚缺网站完整字体目录映射、字体搜索收藏、用户导入、全排版/注释/边框选项。
- 生成器只有基础样式；迷宫只提供矩形 DFS，星空只有单字符星点，图案只有三种基础纹理。不具备完整网站参数清单。
- 文本工具为基础版本；没有完整分析热图、逐项问题定位、全部大小写变换、词频或语言可读性分析。
- 导出尚缺 PDF / WebP / 动画、完整字体和主题、编码选择、批量与代码包装。
- Unicode 可分析和按字符簇反转；字符画网格仍按 UTF-16 长度处理，宽字符与字体回退未完善。
- 图片和文字项目保存输入参数；生成器 / 文本工具保存结果快照，不能恢复生成器控件参数。
- 最近项目是本机路径列表，不是素材图库。恢复只有最近结果，切换页面会停止该页面尚未触发的恢复计时。
- 当前是单窗口、各页面独立结果。没有完整多文档、跨工具发送或统一撤销栈。
- 未完成安装包、发行许可证清单和干净机器运行验证。
