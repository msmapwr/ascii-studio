# ANSI 查看器

打开导航中的 ANSI 查看器，选择文件、拖入文件、粘贴原文，或载入内置示例。首次解析自动开启图像预览；“显示”中可切换纯文本，预览缩放沿用结果栏的按钮和快捷滚轮。

## 支持范围

- 文件选择提供 ANS、ANSI、ICE、NFO、ASC、DIZ、LIT、DRK、TXT。最多 4 MiB 文件或 UTF-8 粘贴文本，最多 2000 行，20–300 列，默认 80。
- 自动严格检查 UTF-8，失败后使用 CP437；可在 ANSI 设置手动切换。ASCII 文件两种编码结果一致；不保证能猜中所有旧文件。粘贴文字已经是 Unicode，不再按文件编码解码。
- SGR：重置、亮色、标准/高亮 16 色、256 色、24 位 RGB、前景和背景、反色、隐藏；闪烁静态显示，iCE 将闪烁标志转为高亮背景。
- 光标：CSI A/B/C/D/E/F/G/H/f/d/a/e、保存 s/u 和 ESC 7/8；擦除 J/K；CR、LF、BS、8 列 Tab。LF 按艺术文本换行到首列处理。支持延后自动折行，满行后的 CRLF 不额外插入空行。
- OSC/DCS/其他控制字符串只跳过，未知和未完成序列统计。不会打开链接、播放声音、执行终端命令或访问网络。8 位 C1、字符集切换、下划线/斜体、滚动区域和完整终端模拟不在首轮支持范围。
- SAUCE 00：尾部 128 字节记录、CP437 标题/作者/组/日期、宽高、iCE 标记和有效 COMNT 注释。移除元数据与尾部 EOF；不信任 FileSize 字段。异常注释块会提示，过短或未知记录不会越界。

## 项目与导出

保存项目保留当前结果、原始文件字节（文件来源）、Unicode 原文（粘贴来源）、编码、列数和 iCE 参数。重开先显示保存的结果；点击查看才重新解析，手工编辑的结果不会在打开时重生成。

PNG/JPEG/GIF、HTML、SVG、ANSI 和 JSON 保留前背景色；TXT、Markdown 是纯文本。彩色 ANSI 导出统一使用 24 位前背景色、CRLF 换行与末尾重置，不写入原始控制命令或 SAUCE 记录。超出位图像素预算时，预览切换为文本，可降低字号或导出倍率。

旧项目没有 BackgroundColors 字段时保持原行为。生成的纯文本手动编辑后，颜色会重置；可使用原文重新解析。Unicode 网格按字符簇和显示列计算，中文与 emoji 使用双列；实际字形仍取决于字体和终端。资源边界见 Unicode 与视图专题。
